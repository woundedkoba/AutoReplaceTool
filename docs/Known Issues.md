AutoReplaceTool Known Issues
------------------------------------------------------------

AutoReplaceTool v0.1.0
- Only the five tiered families currently supported by Paper materials are eligible for lower-tier fallback: pickaxes, axes, shovels, hoes, and swords.
- Behavior should still be validated on a live Paper 26.3 server, especially for off-hand item break events.
- Bukkit and Spigot compatibility is not guaranteed because Paper is the primary supported platform.
- The build uses the Paper API alpha build `26.3.build.38-alpha`; a stable 26.3 API build should be adopted when available.
